```
{{name}} — thanks for having us template / measure at {{site}}.

```

**T+5 bump**

```
Checking in on the {{site}} countertop quote. Still hold {{lead_time}} if you book this week.

```
Closing my file on {{site}} unless you want to reopen. Happy to requote if plans change.
